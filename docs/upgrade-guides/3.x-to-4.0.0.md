# Upgrade from Radical.Windows 3.x to 4.0.0

Radical.Windows 4.0.0 is a major release: it moves to .NET 10, removes APIs that have been obsolete since 2.x, and enables validation by default.

## .NET 10

Radical.Windows 4.0.0 targets `net10.0-windows`. .NET 8 support ends on November 10, 2026, and applications using Radical.Windows 4.0.0 must target .NET 10:

```xml
<TargetFramework>net10.0-windows</TargetFramework>
```

## ApplicationBootstrapper

`ApplicationBootstrapper` and `ApplicationBootstrapper<TMainView>`, obsolete since 2.0.0, are now obsolete with an error: code using them no longer compiles. They will be removed in 5.0.0. Use the `AddRadicalApplication` extension method instead, as described in the [1.x to 2.0.0 upgrade guide](1.x-to-2.0.0.md) and in [application configuration](../mvvm/application-configuration.md):

```csharp
public partial class App : Application
{
    public App()
    {
        this.AddRadicalApplication<MainView>(configuration =>
        {
            //configuration options previously set on the ApplicationBootstrapper
        });
    }
}
```

## Validation is always enabled

`AbstractViewModel` and `AbstractMementoViewModel` now implement `IRequireValidation`. Setting a validation service is enough to enable validation, and view models no longer need to implement `IRequireValidation` explicitly. Existing view models that do keep working.

View models without a validation service use the default `NullValidationService`, which never reports errors.

## Removed APIs

| Removed | Replacement |
|---|---|
| `Repeat` | A `DispatcherTimer`. |
| `Wait` | A `DispatcherTimer`, stopped in its first `Tick`. |
| `AbstractViewModel.MoveFocusTo<T>(Expression<Func<T>>)` | `MoveFocusTo(nameof(Property))` |
| `AbstractMementoViewModel.MoveFocusTo<T>(Expression<Func<T>>)` | `MoveFocusTo(nameof(Property))` |
| `ObservableEntityCollection<T>.OnPropertyChanged<TValue>(Expression<Func<TValue>>)` | `OnPropertyChanged(nameof(Property))` |
| `DelegateValidationService` | A class inheriting from `AbstractValidationService` that overrides `OnValidate`, see below. |
| The `IConventionsHandler.DefaultViewDataContextSearchBehavior` setter | None: the value is always `ViewDataContextSearchBehavior.LocalOnly`. |

`DelegateValidationService` can be replaced by:

```csharp
class CallbackValidationService(Func<IEnumerable<ValidationError>> callback) : AbstractValidationService
{
    protected override IEnumerable<ValidationError> OnValidate() => callback();
}
```

## XML namespaces

The legacy `http://schemas.topics.it/wpf/radical/windows/*` XML namespaces, deprecated in 2.0.0, have been removed. Use the `http://schemas.radicalframework.com/windows/*` ones:

| Removed | Replacement |
|---|---|
| `http://schemas.topics.it/wpf/radical/windows` | `http://schemas.radicalframework.com/windows` |
| `http://schemas.topics.it/wpf/radical/windows/behaviors` | `http://schemas.radicalframework.com/windows/behaviors` |
| `http://schemas.topics.it/wpf/radical/windows/controls` | `http://schemas.radicalframework.com/windows/controls` |
| `http://schemas.topics.it/wpf/radical/windows/converters` | `http://schemas.radicalframework.com/windows/converters` |
| `http://schemas.topics.it/wpf/radical/windows/effects` | `http://schemas.radicalframework.com/windows/effects` |
| `http://schemas.topics.it/wpf/radical/windows/input` | `http://schemas.radicalframework.com/windows/input` |
| `http://schemas.topics.it/wpf/radical/windows/markup` | `http://schemas.radicalframework.com/windows/markup` |
| `http://schemas.topics.it/wpf/radical/windows/regions` | `http://schemas.radicalframework.com/windows/regions` |
